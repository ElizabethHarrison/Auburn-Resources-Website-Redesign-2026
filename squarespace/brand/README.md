# Auburn Resources brand assets (redrawn, October 2026)

Redrawn from a supplied image of the 2019 logo (D-038). The wordmark is URW Gothic Demi, the nearest openly licensed
match to the original lettering; the waves are redrawn to the original proportions and colours. Replace with the
designer's original master artwork when it is available (Q-55).

| Folder | Contents |

Variants: primary (full colour), reversed (white, for dark teal or navy), one-colour navy / dark teal / black,
horizontal (full colour and reversed), mark only (waves) in four colourways.

Colours: logo blue `#1586E2` (waves), logo navy `#012361` (wordmark), from the company style guide (Nov 2019).
