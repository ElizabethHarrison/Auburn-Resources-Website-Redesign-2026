## How to answer (for every contributor)

You do not need to know anything about the website. For each item:

1. **Give the value exactly as your source states it.** Do not round, estimate or rephrase figures. If the answer is
   "unknown" or "not applicable", say so — a gap is fine; a guess is not.
2. **Name the source**: the document the value comes from (e.g. "share registry report", "tenement schedule",
   "board minutes", "ASX-style announcement of 12 Mar 2021"). Send the document, or tell us where it is kept. Internal
   sources are never published; they are recorded so the value can be traced (D-025).
3. **Give the as-at date**: the date on which the value is true (DD MMM YYYY). Values change; the site shows the date.
4. **Say who can verify it** if that is not you.
5. **Supply files as originals**: PDFs as issued (not scans of printouts), images at full resolution, documents as
   Word (`.docx`) for text we will lay out, GIS as shapefile or GeoJSON.

Text types, so you know why some answers have limits:

| Type | What it is | Rules the website enforces |
| --- | --- | --- |
| **Fact** | one value: a number, date, name, percentage, address | needs a source document and an as-at date |
| **Technical or corporate statement** | reviewed prose making a claim | needs at least one source document; numbers are kept exactly as written |
| **Narrative** | short plain text (introductions, headings) | **no digits at all**; some have a character limit |

## What happens after you answer

1. The web team enters your answers into the content system (Sanity) as **"to verify"**. Nothing is published yet.
2. The **approver** reviews each item in the Sanity Studio and marks it approved, which records their name and the
   date. Only the company secretary (corporate content) or the competent person (technical content) can approve.
3. The website shows **only approved content**. Anything not approved is hidden (never half-shown), and a report
   lists what is still missing before each release.
4. Approvals have a **review-by date** (12 months after the as-at date unless you set one). After it passes, the
   item stays visible but is flagged for re-checking.

## What we will never do

Invent or "improve" a fact, figure, date, name or title; draft legal text, disclaimers or competent-person statements
as final copy; name Traditional Owner groups without recorded consent; publish the held-back wording listed in
`competent-person.md` CP-7.4; publish anything that has not been approved by the right person.
